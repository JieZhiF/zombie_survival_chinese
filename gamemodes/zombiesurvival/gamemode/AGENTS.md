## OVERVIEW

## CONVENTIONS

- Files open with a Chinese header block summarizing purpose and listing every global/function/hook defined; update that list when adding globals.
- obj_*_extend trio: no suffix = shared, _sv = server, _cl = client. Add methods to the matching realm file.
- New net.Receive handlers go only in cl_net.lua; server sends register strings in GM:AddNetworkStrings (init.lua).
- Mutations register in sh_zombieshop.lua (GM:AddMutation); their purchase logic lives in sv_concommands.lua.

## ANTI-PATTERNS

- mapeditor.lua is concommand-driven entity placement, NOT a visual editor; don't hunt for editor UI here (UI is vgui/).
- cl_dermaskin.lua and cl_dermaskin_b.lua are two skins; the forced "zombiesurvival" skin hook is only in _b.
- Already flagged in root AGENTS.md, all located in this dir: sv_profiling.lua is not perf profiling; sh_options.lua is the shop DB, not settings; TrueVisibleFilters deprecated (sh_util.lua); ammoexpand stubs; self.BaseClass TODO (sh_weaponquality.lua); buffthefps load order (perf/).
